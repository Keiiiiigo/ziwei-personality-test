# 紫微斗数人格测试

输入出生日期和时间，自动排紫微命盘，生成一份人格分析报告。点开链接就能测。

在线地址：https://keiiiiigo.github.io/ziwei-personality-test/

## 能测到什么

- 十二宫命盘图：命宫、兄弟、夫妻、子女、财帛、疾厄、迁移、奴仆、官禄、田宅、福德、父母，标清每宫的宫名、主星、辅星和四化
- 命盘总览：命主、身主、五行局（水二局 / 木三局 / 金四局 / 土五局 / 火六局）、命宫主星、幸运色
- 4 个关键词加一句话总评
- 核心性格、优势、盲点、人际情感、事业财运、成长建议 6 个板块
- 每条结论都带命理依据，可展开查看，出处包括《紫微斗数全书》《太微赋》等

## 怎么用

1. 填姓名（选填）、性别
2. 填公历出生日期（年-月-日）
3. 填出生时间，三种方式任选一种：
   - 直接选时辰（子时 23–1、丑时 1–3……亥时 21–23）
   - 输入具体几点几分，自动换算成时辰
   - 不清楚出生时间：按午时推算，结果页会明确标注“未提供准确时辰，按午时推算，仅供参考”
4. 出生地（可选，精确到市）：先选省，再选市，支持搜城市名
5. 点“查看我的命盘”，看十二宫命盘和报告

## 出生地与真太阳时

出生地会参与排盘，不是只做展示。

输入几点几分（按北京时间理解）并且选了出生地时，页面按真太阳时自动校正再定时刻：

真太阳时 = 北京时间 +（经度 − 120°）× 4 分钟

例如泰州经度约 119.9°，时差约 −0.4 分钟，基本不动；乌鲁木齐经度约 87.6°，时差约 −129 分钟，11:30 北京时间会校正为 9:21，午时变巳时，命宫、身宫、五行局和主星都会跟着变。结果页会同时显示北京时间、真太阳时、校正前后的时辰和有没有跨时辰。

直接选时辰时，默认那个时辰就是真太阳时辰，不再重复校正；没选出生地时，按北京时间直接定时刻，并注明未做真太阳时校正。

出生地选择器内置 368 个城市及经度，只含地级市、直辖市和省直辖县级市（例如湖北天门、仙桃、潜江，河南济源），带“省直辖县级市”标注；不收市管的县级市，例如靖江、泰兴、昆山、义乌。

## 排盘规则

- 公历转农历内置在页面里，不调外部接口；闰月前半月算本月，后半月算下月
- 寅起正月顺数至生月，再逆数至生时安命宫、顺数至生时安身宫
- 命宫天干由五虎遁推出，命宫干支的纳音定五行局
- 紫微星按五行局与农历生日定位，安星法采用文墨天机通行的《紫微斗数全书》安星表（局数除生日，借数奇逆偶顺）；紫微既定，紫微星系逆布、天府星系顺布，天府与紫微以寅申为轴对称
- 辅星与杂曜按农历月、日、时辰与年干支定位，包括左辅、右弼、文昌、文曲、天魁、天钺、禄存、天马、擎羊、陀罗、火星、铃星、地空、地劫等
- 四化按出生年干起化禄、化权、化科、化忌
- 同一份输入每次结果相同，不用随机数；不编造没有提供的经历、数据或成果

## 分享与保存

结果页的“生成分享图”会用浏览器原生画布画一张完整海报，含命盘、主星、关键词、六大板块和幸运色。手机上支持系统分享就直接调起分享面板，不支持就弹出图片预览，长按保存转发。

“保存图片”用同一套画图，点的时候有“生成中”状态，下载的同时弹出预览图兜底，就算下载被拦了也能长按图片保存。

## 技术说明

- 单个 `index.html`，纯前端实现，不需要服务器、数据库和登录
- 农历转换、命宫身宫、五行局、主星辅星、四化全部用内置 JS 算法实现，不调外部接口，核心排盘不依赖外部 CDN
- 响应式，手机上也能看清命盘图和文字

## 部署

本仓库就是部署用的仓库：

1. 进仓库 Settings → Pages
2. Source 选 Deploy from a branch
3. Branch 选 main，文件夹选 / (root)，Save
4. 等一两分钟，打开 https://keiiiiigo.github.io/ziwei-personality-test/ 就能测
